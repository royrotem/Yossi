# Department Annual Graph System

## Quick Start

```bash
docker-compose up --build
```

Open http://localhost:3000

## Features
- Dashboard with charts and KPIs
- Interactive org chart with department details
- Annual goals management with progress tracking
- Milestone timeline view
- Full Hebrew RTL support

## Architecture
- **Frontend**: React + Recharts + react-organizational-chart
- **Backend**: FastAPI + SQLAlchemy + SQLite
- **Deployment**: Docker Compose (single command)
